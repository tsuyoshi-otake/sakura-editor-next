# Configuration and Build Language Basics

This built-in declarative extension highlights INI/properties files, dotenv
files, Makefiles, CMake files, TOML, Git configuration, EditorConfig, and common
service configuration files. It does not execute configuration contents.

The INI, dotenv, and Makefile grammar sources are derived from Visual Studio
Code language-basic extensions under the MIT License. The CMake and TOML grammar
sources are maintained as part of Sakura Editor NEXT.
