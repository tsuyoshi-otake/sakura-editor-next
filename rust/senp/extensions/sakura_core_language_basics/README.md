# Core Language Basics

This built-in Sakura Editor NEXT extension provides TextMate syntax highlighting
for common programming, web, data, and scripting languages. It is declarative:
installing or enabling it does not execute extension code.

The grammar sources are derived from the language-basic extensions distributed
with Visual Studio Code and remain available under the MIT License reproduced in
`LICENSE`. The SENP manifest, package integration, language selection, and editor
rendering are Sakura Editor NEXT implementations.
