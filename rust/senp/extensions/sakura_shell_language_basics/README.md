# Shell Language Basics

Built-in declarative SENP language support for POSIX shell families, Bash,
zsh, ksh, csh/tcsh, PowerShell, and Windows Batch. It contains no executable extension
module and sends no document text outside Sakura Editor NEXT.

The `source.shell` and `source.powershell` grammars are imported from the MIT
licensed Visual Studio Code built-in language extensions version 10.0.0. The
csh/tcsh grammar is maintained by Sakura Editor NEXT because csh syntax is not
the same language as Bash syntax.
