# Projects

This built-in declarative extension contributes the Projects ViewContainer.
Sakura Editor NEXT retains ownership of the saved Project catalog, active
WorkspaceContext, Git worktree discovery, workspace activation, native drawing,
focus, and accessibility. Agent worktrees are a child provider beneath the
current Project, not a second top-level workspace authority.

The package receives no filesystem, process, credential, or native-window
authority.
