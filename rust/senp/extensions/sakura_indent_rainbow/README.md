# Indent Rainbow

Indent Rainbow makes leading indentation easier to scan by filling each visual indentation level with one of four repeating translucent colors.

## Features

- Handles spaces, tabs, and mixed indentation using the editor's current tab size.
- Colors the complete width of every indentation level in the classic indent-rainbow style.
- Processes only the visible, revision-tagged text supplied by Sakura Editor NEXT.
- Produces presentation-neutral decoration slots; it does not draw or access editor windows directly.

## Privacy and security

This built-in extension has no filesystem, network, process, shell, environment, or native-window access. It receives only visible text and tab size and returns bounded decoration metadata.
