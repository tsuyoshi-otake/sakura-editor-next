# Legacy Language Basics

Built-in declarative SENP highlighting for Perl, COBOL, and both fixed-form
and free-form Fortran. Fixed and free Fortran are separate language identities
because their continuation, comment, and column rules differ.

The Perl grammar is imported from the MIT licensed Visual Studio Code built-in
Perl extension version 10.0.0. COBOL and Fortran grammars are maintained by
Sakura Editor NEXT. This extension contains no executable module.
