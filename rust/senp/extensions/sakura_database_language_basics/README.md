# Database Language Basics

Built-in declarative SENP support for SQL, Oracle PL/SQL and SQL*Plus, Oracle
Net files (`tnsnames.ora`, `listener.ora`, and `sqlnet.ora`), PostgreSQL,
MySQL/MariaDB, ODBC, Flyway, and Liquibase configuration.

The generic SQL grammar is imported from the MIT licensed Visual Studio Code
built-in SQL extension version 10.0.0. Oracle and configuration grammars are
maintained by Sakura Editor NEXT. This extension has no executable module.
