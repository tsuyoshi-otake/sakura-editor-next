# Infrastructure Language Basics

Built-in declarative SENP highlighting for Dockerfile/Containerfile, Compose,
Terraform/HCL, Azure Bicep, AWS CloudFormation and CDK configuration,
Kubernetes/Kustomize, Helm, GitHub Actions, and Azure Pipelines.

The Dockerfile grammar is imported from the MIT licensed Visual Studio Code
built-in Docker extension version 10.0.0. The remaining grammars are maintained
by Sakura Editor NEXT. This extension has no executable module and does not
contact a marketplace or cloud service.
